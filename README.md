# MSU Computer Graphics

An interactive 3D OpenGL scene created as a computer graphics course project. It uses GLSL
shaders and supports runtime control of fog, depth of field, anti-aliasing, and
post-processing effects.

Интерактивная трёхмерная сцена на OpenGL для учебного проекта по компьютерной графике.
Использует GLSL-шейдеры и позволяет во время работы управлять туманом, глубиной резкости,
сглаживанием и постобработкой.

## Описание

В реализации используются GLFW, GLEW, GLM и PNG-текстуры. Можно перемещаться по сцене и
настраивать FXAA и другие графические эффекты во время работы.

В репозитории вместе хранятся код сцены, шейдеры, текстуры и управление. Это самостоятельная демонстрация, а не переиспользуемый графический движок.

## Разработка и проверка изменений

**Основные точки изменения:**

- `src/computer_graphics.cpp` - основная программа, управление сценой и обработка эффектов;
- `shader/` - вершинные и фрагментные GLSL-шейдеры;
- `glslprogram/` - загрузка и использование GLSL-программ;
- `mesh/` - геометрия и отрисовываемые примитивы.

**Поток кадра:** сцена сначала рисуется в `renderFBO` с цветовой и
глубинной текстурами. Затем полноэкранный прямоугольник рисуется в стандартный
framebuffer через программу `shader/3.vert` + `shader/3.frag`, получающую
обе текстуры и флаги постобработки. Обычные объекты используют другие
программы из `shader/`; управление эффектами находится в `key_callback()`.
При изменении глубины резкости или FXAA учитывайте обе стадии, а не только
фрагментный шейдер отдельного объекта.

**Связанные изменения:** при добавлении uniform требуется согласовать имя
в GLSL и вызовы `setUniform()` в `src/computer_graphics.cpp`. При изменении
размера окна `window_size_callback()` обновляет viewport и размеры текстур.
Пути к шейдерам и текстурам задаются относительно текущего рабочего каталога,
поэтому перемещение ресурсов затрагивает как C++, так и инструкцию запуска.

**Проверка изменений:** После правки шейдера проверьте его загрузку и
визуальный результат, после правки постобработки - оба прохода рендеринга,
изменение размера окна и переключатели эффектов. Автоматических графических
тестов в репозитории нет.

## Требования

Ubuntu:

```sh
sudo apt update && sudo apt install -y \
    build-essential \
    libglm-dev \
    liblodepng-dev \
    libglfw3-dev \
    libglew-dev \
    cmake
```

## Сборка

```sh
cmake --preset release
cmake --build --preset release
```

Исполняемый файл:

```text
build/release/computer-graphics
```

Шейдеры и текстуры открываются по путям относительно каталога `build/`, поэтому запускать программу удобнее из него:

```sh
cd build
./release/computer-graphics
```

## Управление

| Клавиша | Действие |
|:---:|---|
| WASD | Перемещение |
| P | Post effect |
| E | Depth of field |
| F | Fog |
| X | FXAA |
| +/- | Смена текстуры стены |

## Структура проекта

- `src/` - основной код сцены и render loop;
- `shader/` - vertex/fragment GLSL shaders;
- `texture/` - текстуры и normal maps;
- `mesh/` - геометрические примитивы;
- `glslprogram/` - вспомогательная обертка для GLSL programs.
